# App Launch OS — Starters & Boilerplates

Welcome to the `starters/` directory.

## What is this folder for?

This directory will host production-ready starter templates for building premium mobile apps.

## Available Starters

### 1. [`starters/expo-ts/`](expo-ts/README.md) (Available ✅)
A complete, battle-tested starter template for Expo and React Native:
- **Framework:** Expo SDK 57+ (React Native 0.86, Bridgeless Mode + Fabric New Architecture).
- **Language:** 100% TypeScript with strict typing.
- **Styling:** NativeWind v4 (Tailwind CSS) with 3-layer design tokens.
- **Components:** gluestack-ui primitives.
- **Motion:** React Native Reanimated 3 worklets (60/120 FPS).
- **Haptics:** Built-in `useHaptic` hook mapped to 5 interaction types.
- **Navigation:** Expo Router (file-based navigation with deep linking).
- **State & Data:** TanStack Query + Zustand.
- **Store Compliance:** Pre-configured `PrivacyInfo.xcprivacy`, StoreKit 2 restore flow, and in-app account deletion.

To review the architectural decisions behind this starter, read [ADR-001: UI Stack](../decisions/001-ui-stack.md) and [IMPLEMENTATION_PLAN.md](../IMPLEMENTATION_PLAN.md).
